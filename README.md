DESIGN STYLE

The website should look premium, luxurious, modern, and trustworthy.

Follow the design standards of leading international healthcare institutions.

Use:

• Plenty of white space

• Large section spacing

• Clean layouts

• Elegant typography

• Premium shadows

• Rounded corners (16–20px)

• Smooth scrolling

• Fade-up animations

• Hover effects

• Premium medical icons

• Glass effects only where appropriate

• Beautiful section transitions

• Fully responsive layouts

• Accessibility-friendly design

Use high-quality REAL medical photography throughout the website.

Avoid AI-generated doctor illustrations or cartoon medical graphics.

Typography should be clean and modern such as Inter, Manrope, or Plus Jakarta Sans.
